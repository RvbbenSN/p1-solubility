# Nombre del proyecto

**Problema:** qué pregunta química responde este proyecto, en una frase.

**Datos:** fuente, tamaño, licencia y fecha de descarga.

**Enfoque:** curado → featurización → split → baseline → modelo → evaluación.

**Resultado:** métrica principal frente al baseline y frente a la literatura.

**Decisiones y porqués:** lista corta de las decisiones importantes y su justificación.

**Cómo reproducirlo:**

```bash
uv sync
uv run pytest
```
